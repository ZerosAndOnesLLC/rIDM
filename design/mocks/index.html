rIDM · Phase 15 mocks

C2 · Signal v2 — the current direction
  • Everything from C, plus: tenant-tinted ground with the content as an elevated sheet; a dark command bar in both modes; Bricolage Grotesque for titles and numbers; rows with gradient initials, stacked identity, freshness dots and second-step glyphs; a stat strip in the detail panel; a split-panel sign-in; an Overview dashboard with sparklines, attention list and activity feed; an account security score.
A · Vault — custody, instrument
  • IBM Plex Sans + Plex Mono. Dark navigation rail with the tenant as the anchoring object; content on quiet ground. Tables in a single bordered sheet, status as dot + word. Primary button takes the tenant accent.
B · Registry — editorial, calm
  • Source Serif 4 titles, Source Sans 3 UI. Light text-only sidebar with shortcut hints, hairline tables with no box, warm-neutral ground. Primary button is ink (accent on hover and links), so any tenant colour sits quietly.
C · Signal — dense, keyboard-first
  • Hanken Grotesk + JetBrains Mono. Command bar across the top (tenant, search/commands), slim sidebar, 38 px rows with row actions, bulk-selection bar, user detail as a panel over the list. Auth/account pages are looser than the console.

The tenant theme (a primary + contrast pair), the tenant's light/dark policy and the person's own switch are shared with every open mock through localStorage; the Acme sign-in keeps Acme's own pair. The Appearance screen (C) is where a tenant admin would set all of this.
